**PESATRACK**

Pesaplan is a budgeting app that will help users track their expenses and manage their finances as well as set their own goals and targets.

## Features

- **M-Pesa SMS Parsing** - Automatically track expenses from M-Pesa messages
- **Expense Tracking** - Manual and automatic expense recording
- **Budget Management** - Set category-based budgets with alerts
- **Analytics Dashboard** - Visual spending summaries and trends
- **Goal Setting** - Set your own financial goals and targets and contribute to them
- **Secure Authentication** - JWT-based user authentication

## Tech Stack

- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL
- **Frontend**: React Native (Expo)
- **Authentication**: JWT tokens
- **SMS Parsing**: Regex-based M-Pesa message parsing
